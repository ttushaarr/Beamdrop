How BeamDrop Works

A clean, lightweight HTTP/REST and Server-Sent Events (SSE) protocol with zero third-party cloud intermediaries.

macOS Native Stack
  • • Swift 5.9+ & SwiftUI architecture
  • • Native CGEvent synthetic input dispatch
  • • Modern async/await URLSession.bytes SSE streaming
  • • IOKit.ps power source battery monitoring
  • • Native macOS Notification Center integration
Android Native Stack
  • • Kotlin & Jetpack Compose modern UI
  • • Embedded lightweight HTTP socket server on :8765
  • • MediaStore zero-confirmation direct routing
  • • NotificationListenerService for incoming alerts
  • • Foreground service with Wi-Fi High Performance Lock

Frequently Asked Questions

Do I need an active internet connection to use BeamDrop? ▼

No. Core BeamDrop file sharing, clipboard sync, trackpad, and commands work 100% offline. Both devices simply connect to the same Wi-Fi network, personal mobile hotspot, or local router. (Gemini AI Question Solver requires internet on the tablet only to query the Google Gemini Vision API).

How does the AI Question Solver shortcut work? ▼

Pressing ⌘⇧X or ⌥⌘A on your Mac automatically captures a high-resolution screenshot using ScreenCaptureKit and sends it across Wi-Fi to your tablet. Your tablet solves it in the background using Google Gemini AI, displaying the step-by-step logic and code with a 1-tap button to sync the code back to your Mac clipboard (⌘V).

How does BeamDrop compare to KDE Connect? ▼

BeamDrop includes all primary KDE Connect features (touchpad, media player remote, slide clicker, commands, battery status, notifications, find device) but is built natively in modern Swift/SwiftUI for macOS and Kotlin/Jetpack Compose for Android. It has zero Qt or C++ runtime bloat and adds zero-confirmation MediaStore photo/video routing.

Is my clipboard or remote keystrokes private? ▼

Yes. Communication occurs directly between your Mac and tablet over authenticated TCP sockets protected by pairing secrets and SHA-256 tokens stored securely in macOS Keychain and Android Keystore.

Can I install it on multiple Android phones or tablets? ▼

Yes. You can install `BeamDrop-Receiver.apk` on as many Android phones, tablets, or Android TVs as you like. Each device pairs independently with its own 6-digit PIN.
